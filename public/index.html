Dokumentasi

        
Semua endpoint memakai metode GET dan mengembalikan JSON. Video dikirim sebagai tautan, bukan file.


        
GET/api/ai/text2video

        
Membuat video dari teks. Proses bisa memakan waktu puluhan detik.

        

          

            
ParameterAturan

            
              
promptWajib. 3 sampai 500 karakter.

              
ratioOpsional. auto (bawaan), 16:9, 9:16, atau 1:1.

              
soundOpsional. true (bawaan) atau false.

            
          

        


        
Respons berhasil


{
  "success": true,
  "data": {
    "prompt": "a cow in city",
    "ratio": "auto",
    "sound": true,
    "videoUrl": "https://..."
  }
}


        
Respons gagal


{
  "success": false,
  "error": { "code": "RATE_LIMITED", "message": "...", "retryAfter": 42 }
}

        

        

          

            
HTTPArti

            
              
400Parameter tidak valid.

              
405Metode bukan GET.

              
429Kena batas permintaan. Lihat header Retry-After (detik).

              
502Layanan pembuat video gagal atau tidak bisa dihubungi.

              
504Pembuatan video terlalu lama.

            
          

        


        
Batas penggunaan

        
Setiap IP dibatasi 3 permintaan per menit dan 20 per jam. Kalau terus dikirim setelah ditolak, akses diblokir 10 menit.
